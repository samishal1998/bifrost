## Install

```sh
curl -fsSL https://samishal1998.github.io/bifrost/install.sh | sh
```

For Linux and macOS on x86_64 and arm64. The script checks the download against its SHA-256 and puts
`bifrost`, `bifrostd` and `bifrost-tui` in `~/.local/bin`. It never uses sudo.
[Other ways to install](/bifrost/installation/).

## How it works

```text
discovery → registry → policy → desired mounts → reconciler → mount drivers → ~/machines/<id>
```

A daemon, `bifrostd`, finds machines, decides which ones you allow, and keeps their remote paths mounted with
SSHFS or rclone. Finding a machine is never permission to mount it. The `bifrost` CLI and the `bifrost-tui`
terminal UI talk to the daemon over a private Unix socket.

Bifröst is not a VPN, a sync engine or a distributed filesystem. It uses the network and the SSH trust you
already have.
